=============
Owner's Guide
=============

`The Autofac maintainer guide is located in GitHub. <https://github.com/autofac/.github/blob/main/MAINTAINERS.md>`_ It covers what ownership involves, how issues and pull requests get reviewed, and the release process.

Owners follow the :doc:`contributor guide <contributors>` as well, along with the `Code of Conduct <https://github.com/autofac/.github/blob/main/CODE_OF_CONDUCT.md>`_.
