===============
Getting Support
===============

`Autofac's support options are listed in GitHub. <https://github.com/autofac/.github/blob/main/SUPPORT.md>`_ In short: usage questions go to `Stack Overflow <https://stackoverflow.com/questions/tagged/autofac>`_ under the ``autofac`` tag, open-ended discussion goes to `the Autofac group <https://groups.google.com/g/autofac>`_, and bugs and feature requests are issues.

**File issues in the repository for the library you're having trouble with**, not in core Autofac - Web API integration problems belong in `Autofac.WebApi <https://github.com/autofac/Autofac.WebApi/issues>`_, for example. The issue templates ask for the details that make a report actionable: a reproduction, the whole exception with its stack trace, and the versions you are using.
